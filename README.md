Rock Paper Scissors game in C++

A console-based Rock Paper Scissors game where the player competes against the computer over multiple rounds.

## Features
- Choose the number of rounds
- Random computer choice
- Round-by-round winner display
- Final game results (wins, draws, overall winner)

## Concepts Used
- Structs and Enums
- Functions
- Random number generation
- Switch statements and loops

## How to Run
```
g++ main.cpp -o game
game.exe
```
